# 152-ФЗ / КИИ Check (P3)

Апстрим спрашивает про GDPR/CCPA/SOC2 — это к нашему таргету неприменимо. В РФ:
- **152-ФЗ** — обработка ПДн, регистрация в РКН, договоры поручения, штрафы РКН
- **187-ФЗ** — КИИ (если есть гос-клиенты или субъекты КИИ), лицензии ФСТЭК/ФСБ
- Штрафы РКН выросли резко с 2024 — релевантно для tax-risk-style оценки

## When to use

- Любой ИТ-аутсорс по дефолту обрабатывает ПДн клиентов (логины, ФИО пользователей в системах) → 152-ФЗ применим всегда
- Если в `dd-checklist` ответ «есть гос-клиенты» = yes → активировать КИИ-блок
- Если хостит данные клиентов на своих серверах → активировать processing agreements блок

## Inputs

- Регистрация оператора ПДн в РКН (публичная: `https://pd.rkn.gov.ru/operators-registry/operators-list/`)
- Список клиентов (из P1.8) + индикатор «гос/субъект КИИ»
- Договоры с клиентами на обработку ПДн (если хостит)
- Лицензии ФСТЭК / ФСБ (если есть)
- История уведомлений/штрафов РКН (Rusprofile pull)

## Workflow

### Step 1: 152-ФЗ baseline

| Чек | Статус | Риск |
|---|---|---|
| Зарегистрирован как оператор ПДн в РКН | yes/no | если no и обрабатывает — штраф |
| Уведомление о намерении подано (с 09.2022 — обязательно) | yes/no | штраф за невыполнение |
| Политика обработки ПДн (на сайте/в офисе) | yes/no | штраф |
| Согласия на обработку от клиентов / сотрудников | да/нет/частично | штраф per case |
| Договоры поручения с клиентами (если хостит их ПДн) | да/нет/частично | штраф + риск для клиентов |
| ОРД (организационно-распорядительная документация) | да/нет | штраф |
| Назначен ответственный за обработку ПДн | да/нет | штраф |

### Step 2: КИИ (если применимо)

Триггер: есть гос-клиенты ИЛИ клиенты — субъекты КИИ (банки, телеком, энергетика, транспорт, здравоохранение).

| Чек | Статус |
|---|---|
| Категорирование объектов КИИ выполнено | yes/no |
| Лицензия ФСТЭК на ТЗКИ (если работаем с защищаемой инф.) | yes/no |
| Лицензия ФСБ на шифрование (если работаем с криптой) | yes/no |
| Подключение к ГосСОПКА (для субъектов КИИ) | yes/no |
| Аттестованные АРМ для работы с КИИ-системами | yes/no |

Отсутствие лицензий при работе с гос-клиентами — **критический риск**: контракты под угрозой расторжения, штрафы по 13.12 КоАП + риск 274.1 УК.

### Step 3: Денежная оценка (штрафы РКН + риск контрактов)

Актуальные штрафы РКН (`params.yaml` — обновлять):

| Нарушение | Штраф на ЮЛ |
|---|---|
| Невыполнение требований 152-ФЗ (общие) | 60-100 тыс ₽ за факт |
| Отсутствие согласий | 30-150 тыс ₽ за факт |
| Утечка ПДн (с 2024 — оборотные) | до 3% годового оборота |
| Невыполнение требований РКН после предписания | 300-500 тыс ₽ |
| Незаконная обработка без основания | 60-100 тыс ₽ |

Оценка:
```
fine_potential_rub = Σ (нарушение × штраф_max × вероятность_проверки)
```

`вероятность_проверки`: дефолт `0.10` (за горизонт 3 года), `0.30` если есть гос-клиенты или были инциденты.

**Critical add:** оборотный штраф за утечку (до 3% выручки) — отдельная строка `breach_fine_potential_rub: revenue × 0.03`. Это **catastrophic risk**, не складывать с базовыми штрафами.

### Step 4: Output

**Frontmatter:**
```yaml
compliance_152fz_kii:
  rkn_registration: yes
  registration_date: 2018-03-12
  processing_agreements_status: partial
  has_state_clients: yes
  kii_applicable: yes
  fstek_license: no
  fsb_license: no
  fine_potential_base_rub: 850000
  fine_potential_high_rub: 2200000
  breach_fine_catastrophic_rub: 4260000   # 3% от revenue
  flags:
    - severity: high
      category: kii_no_fstek_license
      impact: "контракты с гос-клиентами на 12М ₽ под риском"
    - severity: medium
      category: processing_agreements_partial
      impact: "штраф РКН + риск претензий клиентов"
  confidence: medium
```

## Output contract

См. [PIPELINE_SCHEMA.md](../../../../../PIPELINE_SCHEMA.md), объект `RegulatoryComplianceAssessment`. **Consumers:** P1 (добавляет в общий tax/admin risk), P4 (SPA indemnity), P6.7 (concerns в outbound pack), P7 (catastrophic breach risk → Tier 3).

## Failure modes & guardrails

- **Не путать с tax-risk-scan.** Здесь — административные штрафы РКН и риск контрактов; там — налоговые доначисления. Складываются в P7, но считаются отдельно.
- **Оборотный штраф (утечка ПДн)** — это **catastrophic, low-probability** риск, отдельная строка, не суммируется с базовыми.
- **Если КИИ-блок применим но лицензий нет** — это **deal-blocker**, флаг немедленной эскалации в Tier 3. Часто требует cure pre-close или отказа от гос-сегмента post-close.
- **Не давать юридических заключений** «нарушает 152-ФЗ» — только «признаки несоответствия требованиям X, требует юридической верификации».

## Связанные скиллы
